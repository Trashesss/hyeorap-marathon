# 0002. 판은 서버가 계산한다

- 상태: 정함, 아직 안 만듦
- 날짜: 2026-10-09
- 정한 사람: @cbnuleehyunwoo

## 배경

여덟 명이 같은 판을 하려면 누군가 한 곳에서 판을 계산해야 합니다. 목표는 "많은 사람이 방문하는 사이트"이고, 모르는 사람끼리 공개 방에서 만나는 것을 생각하고 있습니다.

## 검토한 안

- **가. 방장의 브라우저가 계산한다.** 서버는 방 목록과 메시지 중계만 맡는다.
- **나. 서버가 계산한다.** 브라우저는 입력을 보내고 상태를 받아 그린다.

## 결정

**나**를 골랐습니다. **가**는 공개 방에서 이렇게 깨집니다.

1. 방장이 나가면 판이 끝납니다. 이 게임은 꽝을 연달아 뽑은 사람이 창을 닫기 쉬운 게임입니다. 방장을 넘기는 장치는 서버 계산보다 만들기 어렵습니다.
2. 방장이 다른 탭을 보거나 휴대폰 화면을 끄면 브라우저가 계산을 늦추거나 멈춥니다. 그러면 여덟 명이 다 멈춥니다.
3. 방장의 기기가 느리면 모두가 느려집니다.
4. 점수도, 자기가 뽑는 캐릭터도 방장의 브라우저가 정합니다. 조작할 수 있습니다.

두 안의 비용 차이는 작습니다. **가**도 방 목록과 중계를 맡을 서버가 필요하고, 계산 자체는 가볍습니다. 방 하나가 1초에 쓰는 CPU는 개발용 컴퓨터에서 계산 0.7 ms, 전송 0.6 ms였습니다.

## 치르는 값

- 내 조작이 핑만큼 늦게 반영됩니다. 국내 서버라면 수십 밀리초로 예상하지만 재지 않았습니다. 거슬리면 내 캐릭터만 미리 움직여 보이게 하는 보정을 얹어야 합니다.
- 서버를 계속 켜 둬야 하고, 무료 기간이 끝나면 돈이 듭니다.
- 암호화된 연결을 쓰려면 도메인과 인증서가 필요합니다.

## 다시 볼 조건

- 친구끼리 초대 코드로만 하는 게임으로 범위를 줄인다면 **가**로도 충분합니다.
- 서버 비용을 감당할 수 없게 되면 다시 봅니다.
