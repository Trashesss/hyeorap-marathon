# 0008. three.js r128을 CDN에서 불러온다

- 상태: 적용됨
- 날짜: 2026-10-08
- 정한 사람: @cbnuleehyunwoo (도구의 제약에서 나온 선택)

## 배경

게임은 claude.ai의 아티팩트 한 장으로 시작했습니다. 아티팩트는 정해진 몇몇 CDN의 스크립트만 불러올 수 있고, 묶는 단계 없이 HTML 한 장이어야 했습니다. 그 조건에서 쓸 수 있는 조합이 three.js r128의 전역 스크립트와, 같은 판의 `examples/js` 스크립트들(카메라 조작, 후처리)이었습니다.

## 검토한 안

- **가. 지금대로.** r128을 CDN에서 `<script>`로 불러와 전역 `THREE`를 쓴다.
- **나. npm 의존성으로 최신 three.js를 넣고 늘 묶는다.**

## 결정

지금은 **가**를 유지합니다.

- 화면 코드 약 2,000줄이 r128의 방식에 맞춰져 있습니다. 색을 손으로 선형 공간으로 바꾸는 것(`C()`), 후처리 구성이 그렇습니다. 판을 올리면 색과 밝기를 처음부터 다시 맞춰야 합니다.
- 개발 중에는 묶지 않아도 브라우저가 모듈을 바로 읽습니다. 고치고 새로 고치면 됩니다.
- 아티팩트로 시안을 계속 올리고 있어서 같은 조건을 유지하는 편이 쉽습니다.

## 치르는 값

- 인터넷이 없으면 화면이 뜨지 않습니다. CDN이 멈춰도 그렇습니다.
- r128은 오래된 판입니다. 새 기능과 수정이 들어오지 않습니다.
- `src/view/`가 전역 `THREE`에 기대므로 화면 코드를 Node에서 시험할 수 없습니다.

## 다시 볼 조건

- 아티팩트로 올리는 일을 그만두고 직접 호스팅하게 되면 **나**로 옮길 만합니다.
- 파일로 된 3D 모델을 불러오는 등 새 판의 기능이 필요해지면 옮깁니다.

## 근거

- 불러오는 스크립트 목록은 `index.html` 끝에 있습니다.
