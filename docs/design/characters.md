# 캐릭터 설계

지금 있는 36종의 능력과 수치는 [리드미의 표](../../README.md#캐릭터)와 `src/sim/characters.js`에 있습니다. 이 문서는 왜 그렇게 만들었는지와, 아직 만들지 않은 것을 적습니다.

## 만드는 원칙

- **계열을 정하지 않습니다.** 기계, 생물, 물건이 섞여 있습니다. 원작이 스타크래프트의 온갖 유닛에 엉뚱한 이름을 붙여 쓰는 것과 같은 맛입니다.
- **원작의 유닛과 능력을 참고합니다.** 기억으로 쓰지 말고 자료를 확인합니다.
- **능력은 평범하면 안 됩니다.** 처음 만든 25종은 "빨리 달린다", "앞사람을 느리게 한다" 같은 것이 많았고, 해본 사용자가 "너무 평범하고 단순하다"고 했습니다. 그 뒤로 체력, 죽음, 보복, 설치물을 넣고 전부 다시 만들었습니다.
- **꽝이 있어야 합니다.** 걸리면 손해인 캐릭터가 열 종입니다. "꽝이 걸렸다면 죽는 것이 살 길"이 이 게임의 뼈대이고, 그래서 봇은 꽝을 든 사람을 일부러 치지 않습니다.
- **판을 뒤집는 캐릭터는 드물게 나옵니다.** [결정 0004](../decisions/0004-no-rank-based-odds.md).
- **설명은 세 줄입니다.** 능력, 쓰는 법, 상대하는 법. 화면의 카드와 도감, 리드미가 같은 문장을 씁니다.

## 아직 만들지 않은 16종

2026-10-08에 51종 명단을 짰고 36종을 만들었습니다. 아래가 남은 것입니다. 한 줄 설계만 있고, 수치와 모델은 없습니다.

| 이름 | 생각한 능력 |
|---|---|
| 같이 가 | 고른 상대를 내 자리로 끌어옵니다. 한 번만 |
| 저격수 | 거리와 상관없이 한 명을 즉사시킵니다. 두 발 |
| 일시정지 | 나를 뺀 모두를 3초간 멈춥니다. 한 번만 |
| 입 다물어 | 고른 상대의 능력을 막습니다. 세 번 |
| 지뢰밭 | 지뢰를 깝니다. 깐 사람은 밟아도 괜찮습니다 |
| 똥강아지 | 지나간 자리에 장애물이 저절로 떨어집니다 |
| 유리 장수 | 유리 벽을 열 장 세웁니다. 몸집이 큰 캐릭터가 부딪히면 깨집니다 |
| 둥지 | 둥지를 틀면 4점을 받고 바로 다른 캐릭터가 됩니다. 둥지는 장애물로 남습니다 |
| 옆자리 | 누구 옆으로든 순간이동해 한 대 칩니다 |
| 불닭 | 3초간 폭주한 뒤 5초간 거의 못 움직입니다 |
| 담 넘기 | 협곡의 벽이나 다리 옆을 넘어 지름길로 갑니다 |
| 쌩쌩이 | 가장 빠르고 체력이 1입니다 |
| 뺑소니 | 트럭이 땅에 있는 캐릭터를 치고 지나갑니다 |
| 장식품 | 무적이고 못 움직입니다. 로동로봇과 납치범만 옮길 수 있습니다 |
| 빈대 | 고른 상대의 점수 5점을 가져옵니다. 한 번만 |
| 보건 선생 | 4구간에서만 나옵니다. 골인하면 모두 죽습니다 |

맵이 넓어진 뒤([결정 0003](../decisions/0003-wide-loop-with-chokepoints.md))에 다시 본 것은 아닙니다. 담 넘기와 유리 장수는 새 맵의 병목에 맞춰 다시 생각해야 합니다.

## 아직 만들지 않은 규칙: 은신

- 주차 단속은 3초간 서 있으면 보이지 않게 됩니다.
- 물귀신은 늘 보이지 않습니다.
- 다리의 감시탑 가까이에서는 드러납니다.

원작에서 2레인 가운데가 "은폐 유닛도 모두에게 보이는" 자리라는 데서 가져온 생각입니다.

## 알려진 문제

수치는 전부 초안이고, 사람끼리 해본 적이 없습니다.

- **짱돌이 셉니다.** 한 대면 누구든 죽입니다. 봇이 잡으면 닥치는 대로 죽입니다.
- **넓은 구간에서는 설치물이 약합니다.** 가건물이나 포탑 하나로는 일곱 명분 폭의 길을 못 막습니다. 캐릭터 설명문은 아직 이 점을 말해 주지 않습니다.
- **다리에서 떨어지면 캐릭터가 바뀝니다.** 꽝을 버리는 쉬운 길이 됩니다.
- **꽝에서 벗어날 길이 죽는 것뿐입니다.** 흐엉은 무적이라 그 길도 없습니다. 원작에는 원기옥이 있습니다. [조사 자료](../research/original-reroll.md).
