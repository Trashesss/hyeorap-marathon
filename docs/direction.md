# 방향

다음에 할 것, 하지 않기로 한 것, 아직 못 정한 것을 한 장에 둡니다. 정해지면 [결정 기록](decisions/README.md)으로 옮기고 여기서는 지웁니다.

마지막으로 고친 날: 2026-10-09

## 다음에 할 것

순서는 제안입니다. 사용자가 확정한 것은 "최종 목표는 다른 사람들과의 대전"이라는 점뿐입니다.

1. **온라인 대전.** [결정 0002](decisions/0002-server-runs-the-match.md)대로 서버가 판을 계산합니다.
   1. 상태 안에서 선수끼리 직접 가리키는 곳을 번호로 바꾼다.
   2. 상태 한 장을 보내는 형식을 정한다.
   3. 방마다 `createGame()`을 돌리는 Node 서버를 만든다.
   4. 브라우저가 서버의 상태를 받아 그리게 한다. 방 목록, 초대 코드, 대기실을 실제로 잇는다.
   5. 서버를 띄우고 부하를 다시 잰다. [수용 인원 추정](research/server-capacity.md)을 고친다.
2. **사람끼리 해보고 수치를 고친다.** 체력, 대기 시간, 병목의 폭, 다리에서 밀리는 세기. [알려진 문제](design/characters.md#알려진-문제)부터.
3. **남은 캐릭터 16종과 은신.** [설계안](design/characters.md).
4. **소리.**
5. **안쪽 벌칙 트랙 "신세계".** [결정 0003](decisions/0003-wide-loop-with-chokepoints.md)에서 미룬 안.

## 아직 못 정한 것

- **저장소를 공개할지.** 지금은 비공개입니다. 조직의 다른 저장소는 모두 공개입니다.
- **라이선스.**
- **게임 제목.** 저장소는 `hyeorap-marathon`이고 화면의 제목은 "혈압 트랙"입니다.
- **원작의 원기옥을 넣을지.** 원작에는 플레이어마다 두 개씩 가진, 트랙 위의 모든 유닛을 죽이는 물건이 있습니다. 꽝에서 벗어나는 수단입니다. [조사 자료](research/original-reroll.md).
- **다리에서 떨어졌을 때 캐릭터를 바꿔 줄지.** 원기옥을 넣는다면 함께 정해야 합니다. 둘 다 꽝을 버리는 길입니다.
- **화면 품질을 더 올리는 길.** 지금 모델은 전부 코드로 만든 도형입니다. 사용자의 기준은 "스타2에 못 미치더라도 그 정도"이고, 거기까지 가려면 파일로 된 3D 모델이 필요합니다. 사는 것, 생성하는 것, 맡기는 것 가운데 고르지 않았습니다.
- **호스팅.** AWS 프리 티어를 생각하고 있습니다. 무료 기간이 끝난 뒤는 정하지 않았습니다.
